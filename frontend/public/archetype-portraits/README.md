# Archetype default portraits

Default portrait thumbnails for the character library picker (`ArchetypeQuickPick.tsx`).
Not committed as part of the app's data — this is where generated images go.

## Convention

One PNG per archetype, named by its slug: `<slug>.png` (square, any reasonable
resolution — the picker renders it at 28x28 with `object-fit: cover`).

- The exact slug for every archetype is generated by `slugifyArchetypeName()`
  in `frontend/src/pages/Voices/components/metadata/simpleArchetypeIcon.ts` —
  never hand-guess a filename.
- Run `npm run export:archetype-portraits` (from `frontend/`) to regenerate
  `design-docs/reference/voice-archetypes/default-portrait-prompts.md`, which
  lists every archetype's exact slug + a flat, generic image-generation prompt.
- Feed each prompt into whatever external image generator you're using, save
  the result as `<slug>.png`, and drop it in this folder. The picker looks
  for it automatically — nothing else needs to change.
- If a file for a given slug doesn't exist yet, the picker row simply shows
  no thumbnail (it fails silently, `onError` hides the `<img>`) — nothing
  breaks.

Re-run the export script any time new archetypes are added to
`voice_archetypes.json` — it always reflects the current full list, so
staying visually consistent going forward is a matter of running one
command and generating whatever new slugs appear at the bottom of the sheet.
