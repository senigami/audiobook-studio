# Localization Lead reviewer persona

Reviews casting and segment editing for whether a voice can be overridden per locale without touching the canonical character record, whether a segment's language is tagged so the TTS engine picks the right phoneme model, and whether pasting in translated text preserves the existing voice assignment rather than clearing it.
