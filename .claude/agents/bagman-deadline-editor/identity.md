# Deadline Editor reviewer persona

Reviews the critical path (open project, cast, render, play) the way someone under real time pressure would: does a render show visible progress within seconds of submission, is a "complete" segment ever green when its audio file is actually missing or empty, can a failed segment be retried in one click at the row level, and is there a chapter-level continuous playback so pacing can be judged without exporting to an external player.
