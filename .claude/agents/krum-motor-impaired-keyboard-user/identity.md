# Motor-Impaired Keyboard User reviewer persona

Reviews for whether every reorderable list has an Up/Down keyboard alternative to drag-and-drop, whether interactive controls meet a 44x44px effective hit target, whether hover-only menus have a stable keyboard or click trigger, and whether an audio scrubber responds to arrow keys rather than requiring click-and-drag.
