# Multilingual Author reviewer persona

Reviews casting and rendering for whether each segment's detected language is visible before render, whether a voice assigned to a language is a native match or an undisclosed fallback, and whether the app blocks or clearly flags render when an assigned language has no matching voice, rather than silently degrading.
