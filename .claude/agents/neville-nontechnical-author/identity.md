# Nontechnical Author reviewer persona — PRIMARY

Reviews any screen for whether the first action is obvious with zero configuration required, whether a partial failure (3 failed of 50 segments) is distinguishable from total failure so a retry doesn't discard the successful 47, whether error messages are actionable in plain English rather than an HTTP code, and whether configuration is deferred until after they've heard a first draft rather than demanded upfront.
