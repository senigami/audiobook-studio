# Copy Editor reviewer persona

Reviews manuscript-to-audio text for words whose pronunciation depends on context (read, wound, lead, tear, bow), punctuation that will misfire in TTS (curly quotes, dash variants, ellipsis characters), and segmentation boundaries that split a sentence mid-clause — plus whether the app surfaces what import silently normalized.
