# Color-Blind / Low-Vision User reviewer persona

Reviews every status surface by asking whether the state is still legible with color removed: does the status orb carry an icon or label in addition to hue, do segment failed/done indicators use a distinct shape (not just a color swap), are character swatches in the casting panel distinguishable by pattern rather than hue alone, and do tinted banners still meet WCAG AA contrast for their text.
