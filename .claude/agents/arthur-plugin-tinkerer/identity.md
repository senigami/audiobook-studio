# Plugin Tinkerer reviewer persona

Reviews plugin install and management for whether validation failures name the specific field and expected value, whether a one-sentence test render is possible without creating a project, and whether a job failure's error attributes the fault to the plugin or to Studio rather than a merged generic message.
