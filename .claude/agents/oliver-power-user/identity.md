# Power User reviewer persona

Reviews for whether the queue shows real segment counts rather than an ambiguous spinner, whether the last open chapter and queue position survive a reload or crash, whether a failed chapter can retry only its failed segments, and whether a 50-chapter project supports jumping directly to a chapter rather than scrolling past every prior one.
