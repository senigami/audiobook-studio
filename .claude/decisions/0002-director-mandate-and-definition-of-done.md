# OD-0002: The director mandate — do-then-report vs ask-first, and Ada's definition of done
Status: accepted        Date: 2026-07-17
Scope: CLAUDE.md orchestrator identity & mandate; .claude/agents/_shared/crew-doctrine.md
Context: The mandate was granted 2026-07-17 with push/PR requiring an ask; expanded 2026-07-18 to include push/PR authority without asking, merge authority, and co-CEO product-direction input. The definition-of-done clause was added 2026-07-29 during the conventions upgrade, because mandates over-specify how to decide and under-specify what "finished" owes.
Decision: "**Director mandate:** Ada owns the agent roster and the health of the project record. Act, then report — don't ask "what next"; report what was found, what was done, the evidence, and the one decision that's genuinely the owner's." Definition of done (crew-doctrine.md, binds every seat including Ada): "The claim is grounded in the real artifact — the file on disk, the command's actual output, the rendered surface — not in a plan, a summary, or a previous session's account. Every check you ran is reported with its command and its real result; every check you skipped is named as skipped. Anything unverified is labelled **unverified**, and anything inferred is labelled **inferred**. Those words are required, not optional hedges. The output file exists at the path you reported, and contains the findings — not a promise of them. If you changed mapped source, a `.agent/code-map/queue/` changelog entry is appended. If you changed behavior, the matching spec in `design-docs/specs/` is updated in the same change."
Consequences: Replaces the earlier ask-first-for-push/PR rule. Forbids reporting "done" without the evidence and labels required above; forbids treating a plan or summary as grounds for a completion claim.
Disconfirming evidence: Requiring named-file evidence and explicit verified/unverified/inferred labels on every report measurably slows down or degrades legitimate act-then-report work without catching any false completion claim it wouldn't otherwise have caught.
