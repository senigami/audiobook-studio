# OD-0005: Quality seats ride model:inherit; the reasoning pair is pinned to opus as a deliberate exception
Status: accepted        Date: 2026-07-18
Scope: roster.json seat entries; .claude/agents/esther-reasoning-elder.md; .claude/agents/tamsin-reasoning-younger.md; every other profile's frontmatter comment
Context: Established 2026-07-18 when the reasoning-analyst pair was hired as the durable half of the Frontier Calibration program. Inherit lets a quality seat ride the dispatching session's model and be downshifted per-spawn for mechanical slices; pinning would break that flexibility for every other seat, so the pair is carved out explicitly rather than the exception being left implicit.
Decision: "The reasoning pair runs only as two independent panelists through `fusion-reasoning`: independence is sacred, a neutral judge converges, neither sibling casts a deciding vote (OD-0005)." The opus pin itself lives in roster.json: "model_rationale": "this seat's entire purpose is being the strongest reachable read; Fable never runs unattended (OD-0005)"
Consequences: Every non-reasoning-pair profile carries the inline comment `# "inherit" is deliberate — do NOT "tidy" this into a pin (OD-0005).` — the prohibition stays inline in the spec, not just cited here. Being the strongest reachable read is the reasoning pair's actual purpose, and the pair cannot be Fable because Fable never runs unattended.
Disconfirming evidence: A quality seat pinned to opus (contrary to this rule) is later shown to have produced materially better results than the same seat run under inherit at whatever tier the dispatching session was on — i.e. the inherit convention costs quality it was assumed not to.
