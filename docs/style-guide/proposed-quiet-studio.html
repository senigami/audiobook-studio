1Identity & Type

A two-voice geometric system: Space Grotesk for display/headings/eyebrows/nav (structural voice — already in the bundle), Geist for UI/body (functional voice — tabular figures for ETA/queue/timing surfaces). Source Serif 4 strictly scoped to the reading column.

3Surfaces & material

Structural rule: PINNED = SOLID. Only genuinely floating layers earn glass. The topbar above this page demonstrates it — opaque --surface-alt + hairline, zero backdrop-filter.

Pinned (rail / topbar)
--surface-alt + 1px hairline. Zero backdrop-filter. Any surface fixed/sticky to a viewport edge is solid structural material. This is not a taste call — it is a wiring rule.

background: var(--surface-alt); border: 1px solid var(--hairline);
Floating (popovers / sheets / player-while-active)
Translucent fill + backdrop-filter: saturate(180%) blur(28px). Earned by z-order: this layer genuinely floats over scrolling content. Blur tightened 40→28px — lighter on compositor during GPU render.

background: rgba(255,255,255,.72); backdrop-filter: saturate(180%) blur(28px);
Before: everything glass/blurred — static rails, topbar, cards all had backdrop-filter.  →  After: pinned = solid + hairline (no blur). Only floating transient layers get glass. Blur tightened 40→28px.

4Elevation

Each shadow is bound to a named z-level. Surface shadow = function of z-layer. Resting cards and all pinned chrome: --elev-flat (hairline only, no shadow).

Flat
--elev-flat hairline only base / resting cards / ALL pinned chrome
Raised
--elev-raised --shadow-sm elevated / active cards
Floating
--elev-floating --shadow-md popovers / player / dragged
Modal
--elev-modal --shadow-xl dialogs over scrim
Before: per-component inline shadow recipes, no named z-level. After: four named tiers; a developer assigning a shadow picks a tier, not a raw CSS value — stops arbitrary shadow escalation.

5Buttons

Flat solid fill + 1px inset border (pressable cue without glow). No gradient, no glow, no translateY hover lift. min-height 44px. Hover = fill darken only. Dark theme: button label swaps to dark #0d0f14 on the lightened accent.

All variants

Before: gradient fill + accent-glow (box-shadow 0 6px 20px rgba(43,110,255,.45)) + translateY(-1px) hover lift.  →  After: flat solid fill + 1px inset border (box-shadow: inset 0 0 0 1px rgba(255,255,255,.18)) — pressable without glow. Hover = fill darken only. No lift. Active = scale(.985). Dark label (#0d0f14) on dark accent (never white on #6b9fff).

11Focus & motion

Double-ring focus: 3px solid --action-primary + 5px halo. Reduced-motion guard is the first CSS rule (above). Calm-pulse structural exemption via --pulse-duration token + .is-running class.

Focus indicator (tab into this button)

Double-ring: outline: 3px solid var(--action-primary); outline-offset: 2px; box-shadow: 0 0 0 5px rgba(255,255,255,.55). Dark theme halo: rgba(0,0,0,.5). Legible over any surface including glass layers.

Calm-pulse (shared keyframe — progress bar + orb ring)

62% · ETA 2:18
Orb ring and progress fill breathe on the SAME @keyframes — one definition, two places. "Alive and working" reads as coordinated, not dual-channel noise.

Reduced-motion guard

/* FIRST RULE in cascade — before reset, @font-face, :root */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }
  /* --pulse-duration zeroed here */
}
/* .is-running restores pulse — structural exemption, not developer memory */
.is-running { --pulse-duration: 3s; animation: calm-pulse var(--pulse-duration) ease-in-out infinite; }
Before: reduced-motion guard bundled into aesthetic pass (not first rule; cascade-order race possible). Calm-pulse exemption relied on developer memory. Global transition: all 0.2s on buttons. Resting translateY(-1px) hover lift on buttons.  →  After: guard is the LITERAL FIRST rule (cascade-order race closed). --pulse-duration token zeroed by guard; .is-running class restores it — "alive vs hung" wired, not remembered. Button transition is an explicit property list (background-color, color, box-shadow, border-color). translateY lift removed — hover = fill darken only. Spring easing removed from :root (local to popover/sheet/done-pop only).
