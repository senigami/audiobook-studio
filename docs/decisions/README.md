# Architecture Decision Records

ADRs record significant, contestable architectural decisions — the choices a future
engineer or agent might be tempted to reverse. Each ADR captures context, the decision,
and consequences. Specs in `docs/specs/` document *what* the system does; ADRs document
*why* it is shaped the way it is.

When to write a new ADR: a decision that is hard to reverse, non-obvious, or that
alternatives were seriously considered.
