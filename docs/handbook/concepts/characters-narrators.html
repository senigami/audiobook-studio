Characters & Narrators

A project has one narrator by default, plus any characters you define — each mapped to a voice so dialogue sounds distinct.

At a glance
  • Every project has a default narrator.
  • Define characters and give each a voice and color.
  • Assignment drives how each line is read.

The default narrator

Narration uses the project's default narrator voice. It's the fallback for any line not assigned to a specific character.

Characters

Define a character, give it a voice and a color, and assign its lines. Colors make it easy to see who speaks what at a glance in the editor. See Characters.

How assignment drives rendering

Each line is rendered in its assigned voice. Change an assignment and only the affected lines need regenerating. You can assign one line, one character, or all unassigned narration at once.

Coming with 2.0 — AI voice casting can suggest a fitting voice for each character from your library, with a reason for every pick — you stay in control.
