Artifacts, Reuse & Recovery

Studio decides what's done by looking at validated artifacts, not by whether a file happens to exist. That's what makes reuse and recovery reliable.

At a glance
  • Completion = a validated artifact, not a file on disk.
  • Unchanged audio is reused, not re-rendered.
  • Work recovers after a restart.
  • Finished audio lives in an immutable cache.

Validated artifacts vs file existence

A stray file doesn't mean a segment is done. Studio records validated artifact metadata (duration, format, the request it satisfies) and treats that as the source of truth — so a half-written or stale file is never mistaken for finished work.

Reuse of unchanged audio

If a segment hasn't changed, its audio is reused. Editing one line doesn't re-render the rest of the chapter, which is what makes iteration fast and free.

Restart recovery & reconciliation

Studio reconciles state on startup. After a crash or restart, it checks artifacts against expected work and picks up where it left off. See Backups & Recovery.
