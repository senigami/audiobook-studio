Local-First & Privacy

Your manuscript, voice samples, and finished audio stay on your machine. Anything that leaves is optional, opt-in, and clearly disclosed.

At a glance
  • The default engine is local — text and audio never leave your computer.
  • Cloud engines are optional and off by default.
  • When something would leave the machine, Studio tells you first.
  • No accounts, no recurring usage cost to run locally.

What stays local

Everything, by default. With the local engine, your chapters, the voice samples you upload, and every rendered file are processed and stored on your own machine. You can work completely offline once setup is done.

What leaves the machine — only if you choose

Cloud engines are opt-in. Studio supports optional cloud voice engines (enabled with an API key), but none are installed or active by default. If you turn one on, the text to be spoken — and any reference audio that engine needs — is sent to that provider to generate the audio.

Heads up — a cloud engine means some data leaves your device. Studio surfaces this clearly before you use one, and shows which engines send data off-machine.

This is a deliberate trade-off you control, not a default. The Cloud Engines page explains each engine's data behavior.

No silent fallback

Studio won't quietly route your work somewhere else. If a local engine can't do something, it tells you — it does not silently fall back to a cloud service. What runs where is always visible.

Data ownership & cost

  • You own your files. Projects, voices, and output live in folders you can back up, move, or delete.
  • No usage meter locally. The local engine has no per-word or per-minute charge.
  • No account required to install and use the local workflow.
Tip — For maximum privacy, simply don't enable any cloud engine. The local default covers full audiobook production on its own.
