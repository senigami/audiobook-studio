First Run

Once installed, starting Studio is a single command. The first launch does a little extra setup, then opens in your browser.

At a glance
  • Start with the launcher; the app serves on port 8123.
  • First run downloads engine models and creates working folders.
  • Open http://127.0.0.1:8123 in your browser.

Start the server

Run the launcher and wait for it to come up. Under the hood it starts the app (uvicorn run:app) and the managed TTS Server. When it's ready, open http://127.0.0.1:8123.

What happens on first run

  • Model downloads. The local engine fetches its model the first time it's needed; this can take a while.
  • Folders are created. Studio sets up its projects, voices, and working directories.
  • Plugins are discovered. Installed engines are registered with the TTS Server.
Note — First-run model downloads can look like a long pause. Progress is surfaced in the terminal so you can see it's working, not stuck.
