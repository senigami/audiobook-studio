5-Minute Workflow Tour

Here's the whole workflow in one short pass — from an empty project to a finished chapter.

At a glance
  • Create a project and add a chapter.
  • Build or pick a voice and assign it.
  • Generate, review, and fix any lines.
  • Assemble into an audiobook file.

1. Create a project & add a chapter

Start with a project (title, author), then add a chapter by pasting text or uploading a .txt file.

2. Build or assign a voice

Pick a voice for the narrator. Use a demo voice, or build one in the Voice Lab. Assign characters their own voices if the chapter has dialogue.

3. Generate & review

Generate the chapter and listen back. Watch progress in the queue. If a line needs work, edit it and regenerate just that segment.

4. Assemble the audiobook

Assemble finished chapters into an M4B (or MP3). See Assemblies & Export.

Tip — Using the demo library? Every step above works on the sample project right away.
