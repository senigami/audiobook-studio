Requirements

Before installing, make sure your machine meets a few basics. The local engine benefits from a GPU, but you can get started without one.

At a glance
  • Works on macOS, Linux, and Windows.
  • Python 3.11, Node 18+, and ffmpeg.
  • A CUDA GPU is recommended for fast local synthesis.
  • Disk space for models and your audio output.

Operating system

Studio runs on macOS, Linux, and Windows. The easiest install path (Pinokio) is available on all three; see Installation Paths.

Software

  • Python 3.11 — the app and engine environments are built against it.
  • Node 18+ — to build the frontend from source.
  • ffmpeg — for audio assembly and format conversion.
Note — If you install with Pinokio, it sets up most of this for you.

Hardware

A CUDA-capable GPU makes local synthesis much faster, but isn't strictly required to try the app. More VRAM lets heavier engines run comfortably. See Performance & GPU Tuning.

Disk space

Leave room for engine model downloads (fetched on first use) plus your projects and rendered audio.
