Platform Support & Validation

Studio targets macOS, Windows, and Linux. This page lists the per-platform notes and a quick smoke test to confirm a healthy install.

At a glance
  • Install & launch on macOS, Windows, and Linux.
  • Pinokio install & launch flow.
  • First-run smoke test to confirm everything works.

Per-platform install & launch

All three desktop platforms are supported. The launcher provides the equivalent flow on each (run.sh on macOS/Linux, run.ps1 on Windows). Pinokio offers a guided install on each as well.

First-run smoke test

  1. App starts and loads at http://127.0.0.1:8123.
  2. The TTS Server starts and the default engine reports ready.
  3. Create the sample project, build/pick a test voice, and synthesize a short line.
  4. Relaunch the app and confirm your work is still there.
Heads up — If first-run model downloads stall, check your network and disk space — large models take time on the first run.

Platform notes

Platform-specific prerequisites (e.g. build tools, GPU drivers) and any known limitations are tracked alongside the install instructions in the repository.
