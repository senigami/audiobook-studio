Demo Library

The demo library is an optional bundle of a sample project and voices, so the app has something to explore the moment you open it.

At a glance
  • Optional — install it during setup or skip it.
  • Includes a sample project and ready-made voices.
  • Safe to remove later.

What it includes

A small, finished-style project plus sample voices. It's the fastest way to see how chapters, voices, generation, and playback fit together without building anything first.

Installing it

Pinokio can install the demo library as part of setup; from source you can add it during the guided setup. Either way it's optional.

Removing it

Delete the demo project and voices like any other — nothing else depends on them.

Tip — New to Studio? Install the demo library, then follow the 5-Minute Workflow Tour using it.
