TTS Gateway API

Studio as a local TTS backend

Generate speech over HTTP through the engines you've installed — no cloud account required.

  • Local HTTP API with OpenAPI docs
  • Inline for short text; queued + pollable jobs for long text
  • Bearer-token auth and per-IP rate limiting for shared/LAN use
  • Routes through the same managed TTS Server as the app
# Generate speech through your installed engine
curl -X POST http://127.0.0.1:8123/api/v1/tts/synthesize \
  -H "Authorization: Bearer $STUDIO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "Chapter one.", "voice": "gravel-road"}'

API surface is firming up for 2.0; treat the snippet as illustrative.

Plugin SDK

Wrap any engine in five methods

Built-in engines use the exact same contract as community plugins — no privileged path.

class MyEngine:           # StudioTTSEngine
    def info(self): ...           # metadata for the registry
    def check_env(self): ...      # can this engine run here?
    def check_request(self, r): ...  # pre-flight validation
    def synthesize(self, r): ...     # write audio to r["output_path"]
    def settings_schema(self): ...   # JSON Schema -> settings UI
    # optional: preview(r), shutdown()
  • Runs in the crash-isolated TTS Server, never the app process
  • Schema-driven settings render automatically in the UI
  • Declares resources, languages, and asset types in a manifest
  • Copyable template + contract tests in the repo
Engine Bundles · GitLab

Install engines like Stable Diffusion

An engine is just a GitLab repo. Browse a tag, clone it down, update with a pull.

Discover

Browse the GitLab topic audiobook-studio-tts, or paste a repo URL directly.

Install & update

git clone to install, git pull to update. Updates surface as an alert in Settings → TTS Engines (notify-only).

Self-host friendly

Point at gitlab.com or your own GitLab instance. Heavy model weights download separately, so clones stay small.

Safe by design

Strict manifest + folder-name validation before any code loads; engine code is isolated in the TTS Server.

Voice Bundles · Hugging Face

Voices the ecosystem can read

A documented bundle shape that renders on Hugging Face and imports natively into Studio.

// voice.json — the canonical, engine-agnostic voice spec
{
  "spec": "audiobook-studio-voice",
  "spec_version": "1.0",
  "id": "gravel-road",
  "name": "Gravel Road",
  "image": "icon.png",
  "samples": [{ "path": "samples/preview.wav", "primary": true }],
  "languages": ["en-US"],
  "attributes": { "class": "human", "gender": "masculine",
                  "age": "senior", "accent": "us-southern" },
  "tags": ["cowboy", "weathered"]
}
  • Plays a sample right on the Hugging Face page; carries an icon and tags
  • Discoverable by the tag audiobook-studio-voice
  • Published JSON Schema + a copyable template in the repo
  • Rich, structured tags power AI voice casting
