# 05 · Narrator Performer  ☆ INFERRED

**Identity:** "Before I walk into a session I need to know exactly how to say every character's name, what each voice sounds like, and which lines the director flagged for special delivery — and I need all of that in one place, not scattered across three documents and two emails."

## Goals
- Arrive at a recording session with a complete, session-ready package: character pronunciations, voice notes, pickup list, and any director flags
- Preview any character's voice profile to hear the intended tone before performing a line
- Find director performance notes attached to specific segments without hunting through a separate document
- Quickly identify which segments have been revised since the last session so he doesn't re-record unchanged lines
- Maintain consistent character voice delivery across chapters that were recorded weeks apart

## Context & environment *(INFERRED)*
- iPad Pro in the recording booth for script reading; Mac desktop at home for session prep; accesses Audiobook Studio via the local network when the director runs it on their machine
- Hired as the sole narrator for a 12-chapter fantasy novel; the director uses Audiobook Studio to cast characters and add performance notes, then shares access for session review
- Works in two phases: pre-session prep (reviewing the full chapter, listening to voice previews, noting difficult names) and in-session reference (quickly finding a specific segment's notes during a take)

## Key workflow moments
- **Chapter scan:** Opens a chapter and reads top-to-bottom, using character indicators to track speaker changes and spot dense multi-character dialogue sections that need mental prep
- **Voice preview:** Clicks into each character's voice profile to hear a sample before performing — he listens for tone, pitch, and accent so he can calibrate his own performance to complement the cloned voice
- **Name prep:** Searches for unfamiliar proper nouns (character names, place names, invented words) and looks for phonetic notes attached to them; if none exist, he flags them for the director
- **Pickup list:** Before a session, wants a filtered view showing only segments marked "needs pickup" or "flagged for re-record" — this is his session agenda
- **In-session reference:** During a take, needs to quickly pull up the segment he's recording and read any director note without leaving the script view

## Top friction points *(INFERRED)*
- **F1 — No consolidated session brief:** There's no single view that shows all of a chapter's performance notes, phonetic flags, and pickup items together — he has to hunt through individual segment editors or work from a parallel document the director prepared manually
- **F2 — Voice preview buried in casting panel:** To hear a character's voice sample he has to leave the chapter editor, navigate to the voices library or casting panel, find the character, and play the sample — a slow round-trip that breaks session prep flow
- **F3 — No phonetic annotation display:** The app shows segment text as-is; if a producer or editor has attached a phonetic note to a word, it's not surfaced in the chapter editor where the Narrator Performer is reading
- **F4 — No pickup filter:** There's no way to filter the chapter view to show only flagged or pickup-marked segments; he sees the full chapter regardless of what needs attention
- **F5 — Revision visibility requires memory:** If a chapter was revised since his last session, nothing in the editor highlights changed segments — he has to rely on the director telling him what moved

## What they need from the studio
- A read-only "performer view" of a chapter: clean script layout, character names prominent, director notes visible inline, no editing controls cluttering the screen
- A session summary panel: unfamiliar proper nouns flagged for pronunciation, segments marked for pickup, any director notes — all on one screen before entering the booth
- Inline voice preview accessible from the chapter editor without navigating away — clicking a character name plays their voice sample
- A pickup queue filter that shows only segments flagged for re-record, usable as a session agenda
- Visual indication of segments revised since the last render, so he knows where to focus without director guidance

## Review lens — questions they ask of any screen
- "Can I see every character's performance note without leaving the chapter I'm reading?"
- "How do I hear what a character's voice is supposed to sound like before I record a line?"
- "Where is the list of segments I need to re-record for this chapter?"
- "Does this view tell me which proper nouns have phonetic notes attached and which are unresolved?"
- "What happens if I'm mid-session and the director updates a segment note — will I see it?"
- "Can I see which lines changed since my last session without the director having to tell me?"
- "Is there a clean reading view that hides all the production controls I don't need during a take?"

## Red flags that make them quit or distrust the app
- Opening a chapter for session prep and finding no performance notes attached anywhere, with no way to tell if notes exist elsewhere or simply weren't added
- Having to navigate out of the chapter editor to find a voice sample, losing his place in the script
- No way to distinguish which segments are pickups from which are first-takes — results in re-recording clean lines unnecessarily
- Discovering mid-session that the script he's reading was revised after he prepped, with no visual indication of what changed
- Director notes visible only in an edit modal, not inline in the reading view — forces repeated tapping in and out during a session

**Evidence basis:** INFERRED. Interview professional audiobook narrators who work with director-supervised AI-assisted productions, particularly those using remote or shared tools for script delivery; key open question is whether performers prefer a dedicated read-only mode or an inline annotation layer within the existing chapter editor.
