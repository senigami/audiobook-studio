# Persona Review Panels

Use these panels when you need a fast adversarial pass without rereading the full catalog.

## First-Run And Onboarding

- Casual Listener
- Nontechnical Author
- Local Sysadmin
- Offline Privacy User
- Screen Reader Producer

Primary question: Can a new user reach a successful first render without understanding plugins, local services, or queue internals?

## Chapter Editor And Manuscript Flow

- Novel Adapter
- Dialogue Playwright
- Copy Editor
- Dyslexic Reader
- Deadline Editor
- Review-Only Proofreader

Primary question: Does the editor make the next meaningful manuscript, casting, render, or review action obvious without burying the text?

## Casting And Voice Management

- Casting Director
- Narrator Performer
- Plugin Tinkerer
- Localization Lead
- Sensitivity Reader
- Power User

Primary question: Are voice assignment, voice testing, language fit, and performance intent visible enough to avoid bad renders?

## Render Queue And Progress

- Audio Producer
- Queue Operator
- Observability Debugger
- QA Engineer
- Low-Spec Laptop User
- Engine Maintainer

Primary question: Can users and maintainers tell what is active, what is blocked, what failed, and what can be retried?

## Plugins And Integrations

- Plugin Author
- API Integrator
- Privacy And Security Reviewer
- Local Sysadmin
- Automation User
- Release Documentation Maintainer

Primary question: Are plugin/API contracts explicit, safe, and recoverable without engine-specific branching in app core?

## Accessibility And Inclusive Review

- Screen Reader Producer
- Accessibility QA
- Motor-Impaired Keyboard User
- Dyslexic Reader
- Multilingual Author
- Sensitivity Reader

Primary question: Can the same workflow be completed with keyboard, assistive tech, low visual load, and language variation?

## Publish And Release Readiness

- Publisher Ops
- Mastering Engineer
- Rights Manager
- Small Team Marketer
- Release Documentation Maintainer
- Large Catalog Curator

Primary question: Is the output technically complete, legally safe, version-clear, and ready to distribute?

## Support And Recovery

- Support Triage Agent
- Migration And Recovery Operator
- Queue Operator
- Observability Debugger
- Local Sysadmin
- Privacy And Security Reviewer

Primary question: When something fails, is the evidence clear enough to diagnose without guesswork or destructive cleanup?

## Broad Product Design Review

Use this panel for an end-to-end design review when time allows:

- Casual Listener
- Novel Adapter
- Audio Producer
- Plugin Author
- Screen Reader Producer
- Privacy And Security Reviewer
- Publisher Ops

Primary question: Does the workflow remain coherent from first import through publish while preserving local-first trust, accessibility, and plugin boundaries?
